## 关键交互（与源工程 demo.html 行为一致）

- **顶栏右上三键**：**WiFi** = 连接状态浮层（连接方式 / API Base / 延迟 / 在线工位 / 紧急 / 消息）；**锁** = 界面锁定防误触（锁定后工位与指令按钮不响应）；**太阳/月亮** = 昼夜切换（整套配色含工位插画跟随，存 localStorage）
- **布局**：内容区**左右各留 10%**（顶栏、消息条、模块都在中间 80% 的带子里）；工作台在各自模块内**水平居中**，两侧留白对称
- **工位卡**：hover 显示负载条；点击 / Enter 打开右侧抽屉（Esc 或点遮罩关闭）。遥测数据**只在抽屉里看**（点开工位卡），不摆在卡片上
- **工作轨迹**（抽屉里）：**跟对话一样**按时间正序，每一轮「在干什么 → 调用什么工具 → 返回什么」。工具名是标识符不翻译（`ledger.lookup` / `ocr.batch` / `risk.scan`…），左边框按结果取色（正常灰 / 有状况橙 / 出错红）。派单和办结各会追加一轮，接后端后改由 `GET .../agents/:id/trace` 下发
- **抽屉**：负载 / 待处理 / 当前任务 / 遥测 + 六个指令按钮，指令立即写入消息流并改变工位状态；调用记录保留最近 5 条
- **指令语义**（2026-11-07 重定义）：

  | 按钮 | 效果 |
  |---|---|
  | **派单** | 任务量 **+1**、转「工作中」、接任务；遥测 待办+1 积压+2 告警+1 |
  | **向上汇报** | **只标「紧急」，不加次数**；遥测 紧急+1 告警+1 |
  | **上班** | 转「空闲」 |
  | **下班** | 转「休眠」、清任务 |
  | **复位** | 转「空闲」、清任务 |

  **没有「完成」按钮** —— 派单后的自动办结是**后端的职责**，前端不计时、不模拟、不猜。后端办结后回填状态即可（两条路：下发 `done` 指令走 `runCommand()`，或直接调 `onTaskResolved(agentId)`）。办结一律记成功（工位是智能体，**不存在失误分支**，「失败件数」不会因此变化）。离线演示模式下没有后端，任务不会自己收尾 —— 这是预期行为。

  原「启动」已删（语义并入派单）；「暂停」改为下班、「确认」改为上班。遥测增减规则见 `js/api.js` 的 `METRIC_REACT`，只动该工位已有的字段。
- **指令文案映射**：`js/api.js` 的 `COMMAND_LABEL` 是界面中文文案的唯一出处（按钮 / 调用记录 / 消息流标题三处共用），key 为接口契约值不动，改文案只改 value
- **遥测文案映射**：同文件 `METRIC_LABEL` 把 `metrics` 的英文字段名翻成中文并带单位（`p95` →「延迟（95 分位）· 毫秒」），未收录的 key 原样显示，后端加新指标不破坏渲染
- **工具条**（右下）：负载热力（所有工位负载条常显）· 刷新（负载抖动重绘）· 回调调试（跳设置页锚点）
- **回调调试**：按 `workspace + role` 路由到工位；`critical` 级命中时工位转「紧急」并积压 +1；回执区分「已路由至 X」/「落在工作区级」
- **实时性**：时钟 1s 刷新，相对时间 30s 重算，紧急数条件标红
- **AI 助手**（Marvis 式，`assistant.html`）：左侧**对话** —— 问忙闲 / 积压 / 异常 / 在岗，答案从 `state` **实时算**（不接后端 LLM），带**依据块**（排名行 + 进度条）、**动作按钮**（跳对应页面）、**追问 chip**，以及「正在输入…」三点动画；右侧**主动发现**卡（Marvis Actions 式）—— 进页面即算，报出紧急工位、过载积压、未处理紧急消息、长期休眠，各带置信度和建议动作。8 个意图 + 兜底，中英都认

## 中英切换（顶栏左上）

顶栏左上角 `中文 / 英文` 分段控件，当前语言那段实心反白；点一下整屏换语言，选择存 `localStorage["aiwho.lang"]`，三个页面共用、刷新后保持。

**机制**：源码保持中文原样，渲染时走 `api.js` 的 `t(src, vars?)` 查 `js/i18n.js` 的 `I18N.en`，查不到回退原文。所以：

- 中文不需要字典，英文表就是全部英文文案，也是一份「翻译覆盖清单」
- 复合句用 `{var}` 插值：`t("已下发 {cmd} 至 {name}", { cmd, name })` → `Sent {cmd} to {name}`
- **要改英文只动 `js/i18n.js`**，key 必须与源码中文字面量逐字一致（含标点、空格、`{var}` 占位）
- 后端下发的新文案没收录也不会崩，只是回退显示原文

**覆盖范围**（全部）：界面框架（按钮 / 区块标题 / 导航 / 状态名 / 工具提示 / 表单 label）、指令与遥测文案、时间格式、系统消息，以及演示数据（工作区名 / 工位名 / 当前任务 / 消息流事件 / 接口说明）。专有名词保留原样（星辰科技 → Xingchen Tech、INV-233、SET-20261106-02）。

`document.title` 与 `<html lang>` 跟着切换；调用记录存结构化字段、渲染时才翻译，所以切换语言后历史记录也跟着换。

## 接后端（可选，离线可跑）

1. 页面加载先用内置演示数据渲染；
2. 自动尝试 `GET {API_BASE}/workspaces`，成功即整屏切换真实数据（`apiReady`）；
3. 指令与回调：先 POST 后端，成功后本地落状态；后端不可达时纯本地运行。

默认 `API_BASE = "/api/v1"`；跨域部署时在页面里配置：

```html
<script>window.AIWHO_API_BASE = "http://localhost:3000/api/v1";</script>
```

完整接口契约见源工程 `API.md`（SystemOverview / FeedEvent / Agent / WebhookEnvelope 等 23 个端点）。

## 设计令牌（摘要）

**2026-11-07 视觉优化**：页面底色压深到冷灰，让白色面板真正浮起来；深度靠阴影递进（`shadow-sm/md/float`），边框只做分隔；等宽体只留给机器串（编号 / 接口 / 指标 / 时间戳 / 工位铭牌），按钮、表单标签、区块标题改用无衬线。

`--bg #e8ebed · --surface #fbfdfe · --raised #e9f3f8 · --text #0c2a35/#3a5c69/#748f9c · --accent #7ad5ee（亮青填充，压墨字 #243e4c）· --accent-text #0b6c89（青当文字时压深）· --highlight #fffa8d · 状态实底 var(--st-*)（工作中 #7ad5ee/墨字 · 空闲 #5c7c8a · 紧急 #c2413c · 休眠 #d3e0e6）· 圆角 6/8/10/14 · 缓动 cubic-bezier(.22,1,.36,1)`

**配色取自色卡四色**（`#4ed7f1` 主青 / `#6fe6fc` 中青 / `#a8f1ff` 淡青 / `#fffa8d` 淡黄）+ 按钮参考（填充 `#7ad5ee`、字 `#243e4c`）。**亮青做「面」、压深做「字」**：`--accent` 是填充（按钮 / 选中态 / 图表主线），上压 `--on-invert` 墨色；`--accent-text` 是青当文字/描边时用的压深版，浅底上才看得清。淡黄走 `--highlight` 点睛（待办数、演示模式）。状态实底走 `--st-*`、**底与字成对**（`--st-*-ink`），全部跟昼夜切换走，JS 里不写死 hex。

**模块面板内底 = 全局底色**（不做浮起的白卡）。**标题栏整条铺 `--accent`**（亮青 `#7ad5ee`，与底部导航选中项同一个令牌、必然同色），标题文字压墨字 `#243e4c` —— 四个模块的标题栏都是这一条色带。

**模块面板是一间「房间」**：面板浮起（`shadow-md`），地面用细网格 + 由远及近的环境光，工位坐在地上；面板头带一颗**状态灯**，只在该区有紧急工位时才亮红，平时是安静的灰点。

**工位插画是「玻璃屏 + 浅椅背 + 深色剪影」**：玻璃屏（工作时跑「进度条 + 工件过站」流程动画）+ 桌板与桌腿 + 桌角状态灯 + 员工剪影，浅色座椅盖住深色身体、只露脖子以上的头，看着就是靠在椅背上。色值全走 `--art-*` 变量，昼夜两套，换肤不用改 SVG。几何坐标见规格说明书 §6。
