# 生图关键词清单 · AIWHO WEBHOOK 中台

> 用途：给前端页面配图、换掉工作台（工位卡）里的插画。
> 所有图共用一个**风格基座**，生出来才像一套东西，不像东拼西凑的素材。

---

## 一、怎么用

1. **先复制「风格基座」**，拼到每一条 prompt 前面。
2. **人物/机器人口径要统一**：所有图里都是同一个「圆角小机器人」，只换它面前的桌面道具。
3. **要透明底**：在 prompt 末尾加 `isolated on transparent background, PNG cutout`（Midjourney 用 `/rembg` 或后期抠）。
4. **昼夜两套主题**：能用透明底就用透明底，一张图两边都能用；非要带底色的，浅色版底 `#e8ebed`、深色版底 `#12161b` 各生一张。
5. **导出 2 倍图**：卡里的插画显示尺寸只有 130px 左右，生成 1024 宽，用的时候缩到 2x，才不糊。
6. **图里不要出现任何文字**——工位名、数字、状态全由 HTML 叠上去，图里有字就没法复用、也没法做中英切换。

## 二、风格基座（每条 prompt 都要带上）

**中文（喂即梦 / 可灵 / 通义万相 / Seedream）**

> 等距 3D 插画，黏土质感、哑光塑料材质，柔和棚拍打光，轻微环境光遮蔽，石墨冷灰主色调，只用一个信号橙 `#c2410c` 作点缀色，构图干净留白，产品级渲染质感，整体克制安静、不花哨，无文字，无水印

**英文（喂 Midjourney / DALL·E / SD / Nano Banana）**

```
isometric 3D illustration, clay render, soft matte plastic material,
soft studio lighting with gentle ambient occlusion,
graphite cool-gray palette with a single signal-orange accent (#c2410c),
clean minimal composition, generous negative space,
product-grade render, calm and restrained mood,
no text, no watermark, no logo
```

**负面词（negative prompt）**

```
text, letters, numbers, watermark, logo, signature, blurry, deformed,
extra fingers, extra limbs, cluttered, busy background, neon glow,
purple gradient, rainbow colors, glossy plastic, photorealistic human,
harsh shadows, 3D render artifacts, jpeg artifacts
```

**Midjourney 追加参数**（其他工具不用管）

```
--style raw --stylize 150 --no text, letters, watermark, logo
```

## 三、A 组 · 工位插画 8 张（换掉工作台的 SVG，优先做这组）

**统一角色设定**（粘在每条 prompt 前面）：

> 一个方头圆角的小机器人，只有两条发光线当眼睛，哑光石墨灰机身，胸口一颗橙色小状态灯，坐在一张浅色工作台前

**统一收尾**（粘在每条 prompt 后面）：

> 工作台浅灰白，桌面右侧有一台深色显示器，正面视角、略带俯视，物体居中、上下留白，纯色背景

**画幅**：3:2 或 1:1（原 SVG 是 176×126，接近 7:5，3:2 最省事）

## 四、B 组 · 工作区房间横幅 4 张

放在每个模块面板的头部做背景（压很低透明度 + 上方渐隐），或者作战室分区示意。

**画幅**：16:5 或 21:9（横幅）

**中文基座**
> 等距 3D 房间剖面图，一间安静的调度值班室，黏土质感，柔和顶光 + 地面轻微环境光，石墨冷灰主色，只有家具细节用信号橙 `#c2410c` 点缀，细网格地面，整体克制、干净，无文字，无水印

**英文基座**
```
isometric 3D cutaway room, a quiet dispatch duty room,
clay render, soft matte materials, soft overhead light with gentle floor ambient,
graphite cool-gray palette, signal-orange (#c2410c) only on small furniture details,
fine grid floor, calm restrained mood,
wide banner composition, no text, no watermark
```

| 编号 | 工作区 | 房间里该有什么 |
|---|---|---|
| B1 | 客户接待 | 前台台面、等候椅、挂墙的号牌、绿植 |
| B2 | 票据处理 | 扫描工作台、票据传送带、成排文件架、纸箱 |
| B3 | 数据核对 | 两排对坐的桌面、双屏、天平摆件、穿线的线槽 |
| B4 | 风险与交付 | 大屏监控墙、归档货架、装箱区、一台小推车 |

**每张追加**（英文，中文对应翻译即可）：
```
two small rounded robots working at the desks, seen from a wide isometric angle,
room occupies the lower two-thirds of the frame, empty space above for a title
```

## 九、落地注意

- **命名**：`station-intake.png` / `station-contract.png` / `station-entry.png` / `station-review.png` / `station-compare.png` / `station-diff.png` / `station-risk.png` / `station-archive.png`，横幅 `room-*.png`，助手 `assistant-avatar.png`。
- **放哪**：建个 `assets/` 目录，别混在根目录。
- **主题切换**：现在插画的配色走 `css/style.css` 的 `--art-*` 变量，随昼夜切换。换成位图后**图片本身不会跟着换色**——所以要么用透明底（推荐，深浅底都成立），要么浅深各生一套。
- **建议保留 SVG 的部分**：状态灯、图标、负载条、图表不要用生图，它们要跟状态联动、要响应主题，位图做不到。
- **生图优先级**：A 组（工作台插画）> D 组（助手形象）> C 组（hero）> B 组（横幅）> E 组 > F 组。先把 A 组做出来，界面观感就换掉了。
