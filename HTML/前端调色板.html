你这个项目，具体改哪几行

    
对照 css/style.css 里的设计令牌。不换库也能让页面颜色立起来，改下面三处就够了。

    


      

        
1给「强调色」配一个兄弟色

        
现在 --accent 一个人扛所有重点，哪儿都是橙的，反而哪儿都不重点。加一个 --accent-2 用来做「区分」而不是「强调」，比如图表的第二条线、Tab 的选中态。

        
/* 在 --accent 下面加两行 */
--accent: #c2410c;
--accent-2: #0891b2;   /* 青，跟橙互补 */
--accent-2-soft: rgba(8,145,178,.1);

      


      

        
2状态灯拉大色相差

        
你这四个灯是「橙 / 灰 / 红 / 浅灰」—— 只有 2 个色相，扫一眼分不出轻重。四个状态就该四个颜色，跨着色轮放。

        
--lamp-working: #c2410c;  /* 橙 · 干着活 */
--lamp-idle:    #0891b2;  /* 青 · 待命 */
--lamp-urgent:  #b91c1c;  /* 红 · 出事 */
--lamp-dormant: #a8a29e;  /* 灰 · 下班 */

      


      

        
3别再手写一堆浅色了

        
硬编码 rgba(194,65,12,.1) 这种浅色，换主题时得一个一个改。浏览器现在自带混色函数，从主色现算就行。

        
--accent-soft:
  color-mix(in oklab, var(--accent) 12%, transparent);
--track:
  color-mix(in oklab, var(--accent) 8%, #fff);

      


      

        
4背景别纯灰，带点色温

        
整站 --bg: #fafafa 是无彩的中性灰，配什么都发闷。往主色那边偏一点点（5% 以内），画面立刻有温度，又不会显脏。

        
--bg:      color-mix(in oklab, var(--accent) 3%, #fff);
--raised:  color-mix(in oklab, var(--accent) 6%, #fff);
--hairline: color-mix(in oklab, var(--accent) 12%, transparent);
