# 合成测试材料

`mvp/` 中的票据和流水均为软件测试合成材料，不是真实客户数据或有效发票。

生成命令：在仓库根目录执行 `server/.venv/Scripts/python.exe -m app.agents.cli fixtures`。

- 6 张票据：4 张正常、1 张金额差异、1 张重复件。
- 6 条流水：4 笔正常、1 笔差额付款、1 笔缺票付款。
- 差额样例：票据 2,580 元，对应付款 2,850 元，差额 270 元。
- `unclear.png` 为无法确认关键字段的样例。
- `expected_extractions.json` 是人工编制的参考答案，仅供测试断言使用；真实模型不读取此文件。
- `manifest.json` 用于限制本地样例适配器可读取的文件；正式后端自行实现材料读取与业务对账。
