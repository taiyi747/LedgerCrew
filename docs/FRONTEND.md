# 前端开发任务清单

**LedgerCrew · 账清社｜40 小时｜角色 A**

技术栈：Next.js App Router、TypeScript、Tailwind CSS。
代码归属：`web/`、前端使用说明、产品演示和参赛材料。

先阅读 [公共协作约定](PLAN.md)，再按本文件的 FE 编号领取任务。H0 为团队开工时间；每完成一项，在 PR 中附运行方法与验收结果。

## 开工顺序

1. 搭建前端骨架，列出首页、客户订单页、老板工作台、报告页的路由。
2. 与后端确认 OpenAPI 和响应样例；接口就绪前使用同一组约定样例开发。
3. H8 前与后端、AI 联调一张图片上传到真实提取结果的流程。

## 任务与验收

负责人：**前端开发成员**。所有页面使用中文，金额从服务端整数分格式化。加载、空数据、错误、断线、等待人工等状态均需有明确反馈。

- [ ] **FE-01｜H0–H8｜服务介绍与下单。** 搭建 `web/`，展示目标用户、服务范围、经正式配置的价格或“尚未定价”状态、示例交付物和模拟交易说明。表单填写工作室名称、账期，调用创建订单接口后进入订单页。**验收：** 可以从首页创建一笔真实保存的模拟订单；提交失败可重试。
- [ ] **FE-02｜H2–H8｜客户订单页与上传。** 上传票据和 CSV，展示文件列表、大小限制、处理状态，提供开始处理按钮。接入 SSE，刷新时重新读取订单快照。**验收：** 前端上传一张图片，能看到后端真实提取结果；断线和重连状态清楚。
- [ ] **FE-03｜H8–H16｜老板工作台。** 实现用户名/密码与服务端会话登录、订单列表、Agent 任务时间线、异常列表、原始材料和证据展示。提供「请求补充」「保留异常继续」操作。**验收：** 能查看合成票据与流水差额并作出处理决定。
- [ ] **FE-04｜H16–H24｜补充说明与报告。** 客户提交文字和补充材料；老板查看报告草稿、批准或退回；客户查看已发布报告、下载 CSV、打印和提交反馈。**验收：** 未发布的报告对客户不可见，保留异常会在报告中清楚列出。
- [ ] **FE-05｜H2–H30｜公网与体验招募。** 配置 Next.js API 代理及公网隧道，H4 前用手机网络验证入口；H8 起招募体验者。记录至少 3 次潜在用户交流，争取 1 人完整体验。**验收：** 非开发设备可完成客户流程；交流与反馈按实际情况记录。
- [ ] **FE-06｜H24–H40｜测试、README 与比赛材料。** 编写一条 Playwright 主流程，完成类型检查和构建；整理启动说明、三分钟讲稿、实际运行录像、在线地址及原创说明。**验收：** H36 前完成完整彩排，提交材料齐全。

## 需要与队友对齐

- 后端提供 OpenAPI、会话约定、订单快照、SSE 事件、异常与报告样例；前端据此生成类型。
- AI 的工作进度和成果通过后端业务接口展示，前端不直接调用模型或框架内部接口。
- Next.js 负责 `/api` 代理；与后端共同确认 Cookie、SSE、文件访问和公网隧道配置。
- 金额按后端返回的整数分展示，异常依据与报告版本均以服务端结果为准。

## 交给队友的成果

- 可独立启动的 `web/`、锁定的前端依赖和必要环境变量示例。
- 首页至报告领取的可操作页面，以及空状态、加载、错误、断线和等待人工状态。
- 前端启动、类型检查、构建及 Playwright 主流程的运行说明。
- 真实体验记录、演示讲稿、录像与在线入口；业务数据按实际状态展示。
