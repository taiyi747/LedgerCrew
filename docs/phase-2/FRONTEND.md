# 第二阶段：前端开发计划

**LedgerCrew · 账清社｜MVP 验收后启动｜角色：前端开发**

前置计划：[MVP 前端任务](../FRONTEND.md) · [MVP 公共约定](../PLAN.md)。

## 阶段目标与启动条件

将 MVP 扩展为由一位经营者统筹多 Agent 的 OPC 财税服务运营平台，服务 OPC、小型工作室及美团、拼多多等平台上的小微商户。新增商户资料、平台结算、账务分类、政策依据和申报材料体验。

本文件是第二阶段计划。MVP 的下单、上传、识别、基础对账、人工审批、报告交付及恢复测试通过后启动；本阶段按里程碑推进，不占用原 MVP 的 40 小时排期。代码继续归属 `web/`。

首个样例限定为一个地区、一类经营主体、一种申报事项和一个平台数据格式。三人启动时共同确认，由后端记录支持范围与字段，AI 成员核对官方来源；前端展示实际支持项。

## 任务清单

- [ ] **FE2-01｜商户与申报资料。** 在已有客户和订单体验上增加商户档案，收集地区、经营主体类型、纳税人身份、申报事项、所属期及必要材料。区分经营中的“OPC”与具体税务主体身份。**验收：** 客户能确认完整资料；未支持的组合明确提示，缺失项列成补充清单。
- [ ] **FE2-02｜平台结算核对。** 支持首个平台的订单、退款、结算明细与银行／支付账户流水导入，展示字段映射、批次汇总、预计到账和实际到账。**验收：** 可查看订单到结算到到账的证据链，一笔到账对应多订单时仍能清楚核验。
- [ ] **FE2-03｜账务分类与确认。** 展示收支分类、科目建议、依据与待确认项，允许经营者确认或纠正建议。保留原始记录并显示修订历史。**验收：** 平台净到账、订单销售、佣金和退款分别呈现，内部转账不会被展示为新增经营收入。
- [ ] **FE2-04｜官方规则与适用范围。** 展示后端提供的官方来源链接、政策名称、地区、适用主体、有效期、所属期和规则版本，并区分待审核与已确认规则。**验收：** 经营者能查看本次计算为什么采用这条规则；规则缺失、冲突或不适用时有明确处理入口。
- [ ] **FE2-05｜申报草稿与计算追溯。** 展示选定表单版本的申报草稿，将字段关联到票据、流水、账务分类、政策规则及计算步骤。金额使用服务端结果，人工修正经后端重新校验和计算。**验收：** 任一金额字段可追溯；资料变化后旧草稿有过期提示，缺失项不自动填零。
- [ ] **FE2-06｜完整 Agent 运营工作台。** 展示财税运营总管及客户服务、票据识别、经营数据、会计处理、政策研究、税务计算、风险审计、交付运营八个专业角色。增加资料待补、规则待确认、计算阻塞、草稿待审核等待办。**验收：** 一位经营者能看清每项任务、交接和需要自己作出的决定；数据来自实际运行事件。
- [ ] **FE2-07｜审核与申报资料包交付。** 增加申报草稿、账目明细、异常说明、材料清单和规则／计算依据的预览与下载。明确区分“待审核”“已审核可交付”“已交付”，站内交付不显示为税务机关已受理。**验收：** 审批绑定具体版本；草稿变更后必须重审，客户只能取得已发布的资料包。
- [ ] **FE2-08｜联调、回归和用户验证。** 扩充 Playwright，覆盖主体资料、结算核对、分类确认、规则说明、草稿、退回和交付，并回归 MVP。访谈验证商户的代账支出、办理频次和困难。**验收：** 完整流程与旧版主线通过；“一年 1500 元”“每年都报”等以真实调研结果表述。

## 需要队友提供的内容

- **后端：** 商户档案与支持范围、导入映射、结算批次、分类记录、规则版本、计算过程、申报字段及资料包的 OpenAPI 和样例；状态、权限、错误与 SSE 约定。
- **AI：** 八个专业角色说明、真实交接事件、政策和分类建议的证据引用、缺失与冲突信息；所有内容经过业务 API 展示。
- **共同：** 税务申报、财务报表、工商年报分别命名；首个申报事项只展示已支持的字段、所属期和材料要求。

## 里程碑与交付

| 里程碑 | 前端交付 | 依赖 |
| --- | --- | --- |
| P2-0：范围与契约 | 支持范围、页面流程和接口样例对齐 | 三人确认首个场景；后端冻结新增契约 |
| P2-1：数据与账务 | 资料、结算核对和分类确认可操作 | 后端导入／核对；AI 分类建议 |
| P2-2：申报草稿 | 政策依据、字段追溯和人工审核闭环 | 已审核规则、计算引擎和表单映射 |
| P2-3：交付与回归 | 资料包、版本审核、端到端测试与反馈 | 后端发布与下载；AI 风险审计 |

交付前检查：旧 MVP 流程可用；不支持的主体和缺失规则可识别；申报草稿有证据；版本审批有效；交付状态表达准确。第二阶段服务价格与办理周期按验证后的方案展示，MVP 的 19.9 元不自动作为申报服务定价。
