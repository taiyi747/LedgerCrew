1. 业务负责人、前端、AI 与后端完成 `DEC-002`～`DEC-005` 的首发范围确认；AI 提供可追溯的官方来源与表单/材料依据。

3. 后端据 confirmed 决定更新 SupportedScope、RequiredMaterial、Pydantic Schema、OpenAPI 与 Mock；前端/AI 对同一版本契约会签。
